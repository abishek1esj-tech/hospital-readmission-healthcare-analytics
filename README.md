Hospital Readmission & Healthcare Utilization Analytics

Project Overview

This project analyzes hospital patient data to explore patient demographics, hospital encounters, readmission patterns, and healthcare utilization.

Objectives

- Analyze patient demographics.
- Explore hospital encounter patterns.
- Understand patient readmissions.
- Analyze healthcare utilization.
- Identify meaningful insights from healthcare data.

Tools

SQL | Python | Power BI | Excel


Disclaimer
This project is for educational and analytical purposes only and does not provide medical advice.
